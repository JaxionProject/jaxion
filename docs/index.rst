jaxion
======

Jaxion is a scientific research software for conducting astrophysical and cosmological simulations of Fuzzy Dark Matter.
It is implemented in JAX, utilizing automatic differentiation and multi-GPU acceleration.

⚠️ Jaxion is currently being built and is not yet ready for use. Check back later! ⚠️
