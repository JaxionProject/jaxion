About
=====

Jaxion is a high-performance astrophysics/fuzzy dark matter simulation code in Python, leveraging JAX for automatic differentiation and GPU/TPU acceleration.

The code is open-source and available at:

https://github.com/JaxionProject/jaxion

The documentation is hosted at:

https://jaxion.readthedocs.io

The code is developed by `Philip Mocz <https://pmocz.github.io/>`_, launched in 2025.
