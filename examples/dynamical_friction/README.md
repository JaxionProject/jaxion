# Dynamical Friction

Dynamical friction of Fuzzy Dark Matter soliton in an external potential

Philip Mocz (2025)

Usage:

```console
python dynamical_friction.py --res <resolution_multiplier>
```

Takes around 3 (res=1) seconds to run on my macbook (cpu).
