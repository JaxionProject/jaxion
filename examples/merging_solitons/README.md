# Merging Solitons

Merge solitons to form an idealized Fuzzy Dark Matter halo

Philip Mocz (2025)

Usage:

```console
python merging_solitons.py --res <resolution_multiplier>
```

Takes around 4 (res=1) seconds to run on my macbook (cpu).
