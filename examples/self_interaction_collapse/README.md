# Self-Interaction Collapse

Collapse a soliton due to attractive self-interaction

Philip Mocz (2025)

Usage:

```console
python self_interaction_collapse.py --res <resolution_multiplier>
```

Takes around 5 (res=1) seconds to run on my macbook (cpu).
