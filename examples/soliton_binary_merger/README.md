# Soliton Binary Merger

Collide two solitons with opposite phases

Philip Mocz (2025)

Usage:

```console
python soliton_binary_merger.py --res <resolution_multiplier>
```

Takes around 6 (res=1) seconds to run on my macbook (cpu).
