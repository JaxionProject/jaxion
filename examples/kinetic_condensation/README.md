# Kinetic Condensation

Soliton formation in the kinetic regime

Philip Mocz (2025) 

Usage:

```console
python kinetic_condensation.py --res <resolution_multiplier>
```

Takes around 34 (res=1) seconds to run on my macbook (cpu).
